# 答辩演示顺序

使用本轮安装包 `output/apk/AI智囊团-答辩版.apk`。模型功能演示前，在“我的”中配置有效对话 API 并检查连接，保持网络可用。API Key 不在安装包中预置。

1. **首页与双主题。** 展示深蓝科技与明亮专业两种主题，切换后进入不同页面，说明风格在各功能中保持一致。
2. **猜心。** 心里选一个具体对象，例如奶龙；按真实属性回答“是”“否”“不确定”。说明提问和猜测由大模型驱动，猜错会排除候选并继续；只有用户确认“猜对了”才算成功。不要承诺固定轮数。
3. **预测。** 选择一个示例场景，说明它是示例数据；展示输入检查、采样周期、单位和预测步数，运行后解释预测曲线、历史回测及简单基线比较，再导出图片报告。说明这是根据历史数据估计未来，不保证未来准确。
4. **知识库问答。** 在“问知”中点击“一键填入答辩示例资料”，再点击“导入资料”；从资料卡点击“问这份资料”，提问“核心功能是什么，请标注出处”，展开引用核对原文。
5. **角色对话。** 从首页进入角色列表，选择一个角色，展示同一问题在该角色下的表达方式；功能展示到此收尾即可。

在目标手机上提前检查输入键盘、返回导航、主题切换及文件导出。首次预测资源加载和真实模型等待时间取决于设备及接口，演示时如实说明，不用预录答案冒充现场生成。

推荐把答辩重点放在：完整手机界面、模型驱动的猜心恢复、真实本地预测与回测、知识库带出处回答。暂时不增加主题挑战或其他新玩法。
