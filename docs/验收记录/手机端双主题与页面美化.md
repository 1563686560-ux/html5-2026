# 手机端双主题与页面美化

日期：2026-10-09。

## 实施范围

- 深蓝科技：深蓝背景、青蓝主色、轻微光感；首次使用默认采用。
- 明亮专业：浅灰白背景、蓝紫主色、清晰卡片层次；首页入口使用单列布局。
- 首页和“我的”均可切换主题，保存后重新打开仍保持选择；兼容旧版本的明暗偏好。
- 首页突出猜心、预测、角色对话和问知入口；底部导航为广场、猜心、预测、问知、我的。
- 猜心增加视觉标识、真实轮数进度、问答卡片和主次回答按钮；原理说明折叠展示。保留真实模型请求、错误重试、撤回、用户确认和历史记录。
- 预测整理场景卡片、灵敏度选择、结果曲线与图例；主题切换和画布尺寸变化后重绘。报告随主题配色，并独立重绘高清图表。
- 聊天、知识库、设置及其他页面共用主题变量、圆角、安全区和按钮对比度。
- 开发服务忽略 output 验收目录，避免 Windows 在下载图片写入期间因文件锁导致监听器退出。
