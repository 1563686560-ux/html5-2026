# 预测数据检查与结果解释完善

本轮完善手机端预测的数据检查、运行控制和结果解释；保留原有本地神经网络训练、历史回测及基线比较。没有调用付费 API，没有修改猜心逻辑。

## 已完成

- 严格识别数值与科学计数法。日期、非有限数值、带单位文本不再被拆成错误的预测数据。
- CSV 自动选择数值列，保留中间缺失行与空单元格，显示问题位置并阻止训练。引号包裹的千位分隔数值可以导入。
- 检查参考窗口、预测步数、训练轮数与最少样本量；短历史、回测长度不足、恒定序列和异常值给出提示。异常值不自动删除，缺失值不自动填补。
- 用户明确选择采样周期和数值单位，页面、趋势解释、CSV 与 PNG 报告保持一致。默认周期未知，按序号展示；不从日期列自动推断周期。
- 运行可停止，默认 90 秒超时。修改输入或参数清除旧结果并取消正在运行的任务，过期任务不能覆盖新结果。
- 恒定序列使用恒定值方法，无须神经网络训练。零值准确保留，不适用的 R² 和 MAPE 显示“—”；模型异常输出不展示为成功结果。
- 趋势说明明确是最后预测点与最新历史点的首尾比较。回测展示与保持末值基线的误差对比，不承诺未来准确率。
- 修正拟合曲线的历史时点位置，纵轴包含拟合值；大数和很小的数使用科学计数法。

## 边界与交付

单次最多 2000 个数据点，CSV 文件最多 5MB，单个数值绝对值不超过 10¹²。输入应按时间顺序排列、等间隔采样；本轮没有自动重采样或补齐时间轴。

历史回测结果仅描述历史留出数据上的表现，不能证明未来预测准确。猜心命中率仍需要继续改善，本轮不对它作新的准确率承诺。

已更新源码和 `dist` 网页构建；未重新生成或同步 Android APK。
