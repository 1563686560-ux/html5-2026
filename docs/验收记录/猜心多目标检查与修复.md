## 查出的问题及处理

1. 相似句式误拦不同属性：圆形和圆柱形可能被判成重复。补充形状、材料取值的问句比较；同义重复仍拦截，不推断对象事实。
2. 模型已给合法新属性题，但辅助分组不理想被要求修正；后续候选核对也失败后，整轮停在错误状态。现在保留本轮模型生成并通过单问/判重校验的属性题，修正耗尽时可用它继续探索。未通过核对的猜测不显示，不使用本地固定题。已有事实、轮数、确认规则不变。
3. 多轮用途枚举、候选锚定、已肯定名称却继续细分路段等策略问题：加强结构/尺寸/能源/工作方式与跨类别比较，以及常用名称粒度提示。提示词是软约束，不保证模型永远遵守。
4. 旧 scripts/test-deepseek-guess.mjs 复制了游戏逻辑并使用固定备用题及旧模型，不能代表实际应用。已改为直接调用现有真实 store 测试入口；help入口已验证，无额外API调用。
