# 对辩、检索与首页聊天精简

## 改动
- 对辩明确正方支持、反方反对，禁止相同辩手；运行中及中断待继续时锁定辩题和角色配置。
- 中断后保留已完成发言，只重新生成未完成轮；停止、空输出、截断响应不计为完成。
- 双方以主题主色和警示色区分；完成后展示双方末轮原文摘录，不伪造裁判评分。
- 资料弱匹配时用现有对话 API 提取最多四个检索短语，六秒超时；强匹配无需额外请求。原文检索严格限定资料范围，生成文本不作为出处。
- 首页缩小宣传区域，主要入口统一为两列；主题入口可选五套主题。
- 聊天资料范围默认折叠；首页新建普通聊天清除上次的单份资料范围。
- 资料导入和原文查找折叠，隐藏检索分数等实现细节。

## 验证
- 全量单元测试：477 通过，8 跳过。
- TypeScript、生产构建、改动文件 ESLint、Android 构建及 APK 签名验证通过。
- 手机真实 IndexedDB + 模拟 API：9 项流程通过，覆盖同义检索、原文引用、资料范围切换、正反立场、失败续接及首页五主题选择。
- 五套主题、320/390 像素、首页/聊天/资料/对辩共 40 组布局检查通过。
- 本轮未调用真实付费 API；模型对具体问题的改写和辩论质量尚未通过真实服务验证。
- 最新 APK 已安装雷电，保留原用户数据。
