# 对话上下文隔离与追问修复

## 改动
- 会话切换、历史分页、搜索跳转均校验会话版本；旧请求不能覆盖新会话，切换后立即解除旧发送锁。
- 会话记录新增可选 documentId，保存并恢复每个会话的资料范围；旧版记录从最新用户问题恢复；新会话默认全部资料。
- 重试锁定原提问范围，删除旧轮期间若切换会话立即停止；会话读取期间禁止发送。
- 回复记录新增 complete/incomplete 状态；失败、主动停止、截断、空输出均不作为完整回复。半截内容仍展示与保存，但不进入后续模型上下文、不抽取长期记忆。
- 省略式连续追问携带最近明确主题与近期问题链；独立新问题不带旧主题，不引用助手回答生成检索词。
- 历史裁剪保留完整用户/助手轮次和当前用户问题，不从助手半轮开始、不带历史孤立用户消息；维持20条上限，未增加摘要请求。
